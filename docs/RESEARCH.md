# 参考产品观察与目录修订

参考：[ColaSkill 中文站](https://colaskill.com/zh/)，2026-10-04。

审查路线：打开首页 → 切换“创作设计” → 打开 Skill 详情。

1. **首页**：搜索、分类与四列图文卡片形成发现入口。图片先展示可做出的东西，标题、短说明、作者与仓库 Star 帮助判断是否适合。
2. **分类**：选中状态明确，卡片随分类切换。本站采用任务维度分类，把来源和 Agent 信息另行呈现。
3. **详情**：主体说明用途并展示完整例图，安装与来源靠近用户作出选择的位置。

## 为什么修改首版

首版使用文字卡片，缺少示例图片；大块首屏与说明让目录出现在较深位置。这弱化了参考产品最有用的部分：通过图文预览，快速发现具体任务和产出。

修订采用已授权 Aceternity AI SaaS Template 的 Blog Page、BlogCard 与 BlurImage，缩短首屏，将图片目录作为主要内容。搜索、分类、收藏与详情继续使用 Aceternity 官方组件。

## 图片与内容选择

目录扩充至 59 个 Skills、11 个来源仓库。新增 9 个有公开样张的社区 Skills，包括宝玉的 6 个视觉技能、宝玉 Design、Taste Skill 和 heytea-style；共采用 18 张作者示例图。Anthropic Theme Factory 使用官方 PDF 样张预览。无公开效果图的条目展示来源项目封面或说明原文预览，并明确类型。

作者示例以固定提交的仓库文件为依据；图片许可单独检查。heytea-style 原创海报遵循 CC BY 4.0 并保留作者署名，其 Skill 源码为 MIT。没有复制 ColaSkill 的图片、品牌或目录文案，也没有把本机私有 Skills 作为公开内容来源。

## 验证范围

浏览与安装入口围绕“发现 → 看懂用途 → 查看来源或安装”设计。适配与安装前置条件来自上游文档；示例请求用于说明任务，作者图片用于展示公开案例。本站未执行这些 Skills，因此不把图片、请求示例或仓库 Star 描述为本站运行与评测结果。

目录版本与许可见 [SOURCE.md](../SOURCE.md)；界面和图片来源见 [THIRD_PARTY.md](../THIRD_PARTY.md)；网站实际检查见 [VALIDATION.md](VALIDATION.md)。
