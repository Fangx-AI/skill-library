# 参考产品观察

参考：[ColaSkill 中文站](https://colaskill.com/zh/)，2026-10-04。

审查路线：打开首页 → 切换“创作设计” → 打开 Skill 详情。

1. **首页**：任务分类、搜索与四列作品卡片一起组成主要发现入口。卡片用标题、短说明、作者与仓库 Star 帮助快速判断。
2. **分类**：选中状态明确，卡片随分类切换。分类同时包含任务、身份与业务场景；新站采用单一任务维度，来源和 Agent 信息另外呈现。
3. **详情**：主体解释用途、展示示例，侧栏集中安装、适合谁与来源信息。安装按钮靠近决定点，减少查找步骤。

新站保留“找到 → 看懂 → 安装”的流程。采用已授权的 Aceternity 黑色模板；内容直接从官方与社区的公开仓库核对，安装命令与插件指南按真实前置条件区分。

本次审查只观察公开页面；未注册账号、下载客户端或运行参考站上的 Skills。
